# Security Policy

## Supported versions

Security fixes are applied to the latest revision on the default branch.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Include the affected file, the unsafe instruction or behavior, a minimal reproduction prompt, the harness used, and the impact you observed.

Do not include live credentials, private repository contents, or other sensitive data in a report. For public documentation errors without a security impact, open a normal issue.

## Security model

System Design Compass contains Markdown instructions and references only. It intentionally ships no executable runtime scripts, pre-approved tools, credentials, or network dependencies. Installing any third-party skill still requires reviewing its contents and the permissions granted by the target harness.
