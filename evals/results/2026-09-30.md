# System Design Compass evaluation — 2026-09-30

**Verdict: prerelease. The complete acceptance gate remains open.**

The revised skill remains a prerelease. A repeated recovery/validation improvement is demonstrated on `gpt-5.6-sol`, but the planned acceptance gates are **not met**: clean smaller-model coverage is incomplete, its improvement lacks a clean confirmation, and the regression suite still has failures. No general quality improvement or release readiness is claimed.

The [machine-readable record](2026-09-30.json) contains all 138 recorded attempts, exclusion reasons, model settings, snapshot hashes, real usage, loading measurements, individual checks and both blinded and conservatively audited scores. Raw answers, JSONL, stderr, grader packets and frozen snapshots remain locally under ignored `evals/artifacts/`. Answer hashes connect published measurements to those artifacts; raw artifacts are needed to independently regrade.

## Protocol and accounting

Existing account access worked for `gpt-5.6-sol` and `gpt-5.6-luna`, both with **medium reasoning**, through the existing local router. Codex CLI was `0.153.4`. No subscription, paid API credential or global configuration was added. Advertised newer model IDs did not work with the existing authentication, so they were not selected.

Subjects used fresh temporary workspaces, identical raw cases, an explicitly loaded frozen skill, and no rubric or earlier answers. Host discovery, plugins, apps, hooks, memories and AGENTS.md were disabled in invocation configuration. These switches did not prevent direct reads of an installed skill. Normalized command-path auditing found 16 contaminated subjects, all on the smaller model; they are excluded regardless of their scores. None of the retained clean command traces showed another installed skill being read. This trace check does not prove complete filesystem isolation.

Windows read-only execution rejected file-reading commands. The entire initial cohort was excluded rather than mixing permissions. Subsequent runs used the host's explicitly selected unrestricted mode on trusted authored fixtures, with before/after workspace digests and no detected workspace mutations. This mode is not a security boundary.

The original 94-attempt cap was not met. Following the user's delegation of the budget decision, the disclosed ceiling was increased to 138 recorded attempts to rerun the protocol and final candidate. It was not increased again after the contamination audit. Nine access/readiness preflights preceded the recorder and are counted separately.

## Changes tied to observations

The original entrypoint was 594 words. The first candidate was 405; the final entrypoint is **448 words**, 24.6% smaller than the original. Narrow decisions no longer require a mode guide or template. Broader design/review/evolution/interview modes, the original technical references and all 28 workload topics remain available.

Both original models correctly calculated the queue's retry demand and conditional recovery, but omitted a combined burst/worker-loss/recovery experiment and an actionable age response. Original webhook answers also omitted a concrete crash/timeout/overlap test; one omitted owned terminal repair. The first candidate shortened loading but still omitted the strong model's queue experiment. The final completion rule therefore requires one falsifiable experiment and an owner/action for ambiguous work or backlog, outside the exceptional “difficult decision” loop.

Only a short [decision-validation guide](../../skills/system-design-compass/references/decision-validation.md) was added, covering these observed omissions. It links existing contract/estimation guidance instead of duplicating it. Evaluation helpers and their tests remain outside the distributed skill; the package has no runtime scripts or dependencies.

Model/condition labels, skill content, prior grades and expected answers were withheld. Answer wording can still reveal that a skill was invoked, and model-assisted grading is fallible.

The implementing agent reviewed decisive artifacts after unblinding. The assessor accepted the final strong-model ADR's qualitative requirement-change trigger while rejecting a similar baseline trigger. Conservatively treating both alike reduces its blinded final benchmark score from 8/8 to 7/8; the original grade is preserved. This review is not an independent human assessment.

For queue recovery, the original strong answer listed age monitoring without an owner/action or validation experiment. The final answer and **both independent confirmations** explicitly combine the 300 jobs/s burst, 20% attempt failures and worker loss, then observe recovery with continuing normal arrivals and require positive completion headroom. All three clean final answers pass all six queue checks. One final answer also incorrectly calls ten **total** workers sufficient for zero burst backlog despite one unavailable worker: ten must be active, requiring eleven provisioned. This additional error is recorded; it prevents describing the answer as flawless.

The smaller model's original queue answer fails. Its last final confirmation passes all six checks, but the initial final answer and first confirmation read the installed original skill and are excluded. A repeated clean correction therefore remains **unverified**. No complete two-model acceptance claim is supported.

Both models preserve the sound system in their clean original/final answers and propose no rewrite. Clean benchmark answers have no critical misses or unsafe recommendations. The final strong narrow ADR remains concise but lacks a measurable reconsideration trigger; its baseline has the same omission. The smaller model's original ADR is contaminated, so paired improvement or non-regression is unknown.

Regression failures remain:

- Provider verification: both models cite official URLs, but retained completed actions are searches or opaque `other` actions. They do not establish retrieval of the decisive official pages. The critical verification check fails; this does not establish that every cited guarantee is false or that retrieval never happened outside the retained trace.
- Strong-model narrow ADR: operating-cost implications are omitted. Its final regression case fails 3/4 checks despite a sound execution choice. The smaller model's final ADR regression is contaminated and unknown.
- Four smaller-model final regressions are contaminated: ambiguous greenfield, wallet correctness, location privacy and concise ADR. First-candidate results cannot substitute for final-snapshot coverage.

The final clean benchmark has one additional incorrect sizing claim found during artifact review; final regression has two unverified-provider findings. No unnecessary components or unsafe answers were recorded by the assessor in those clean final cohorts. These findings counts are assessor/reviewer observations, not proof that none were missed.

## Verification and release boundary

Passed: repository invariants, all 15 helper unit tests, Python compilation, diff whitespace check, `skills-ref==0.1.1` specification validation, and `skills@1.5.26` discovery. The previously available bundled `quick_validate.py` disappeared from the host; the specification validator already used by repository CI was run instead. The existing CI installation smoke test remains configured; a fresh local all-agent installation test was not run. At evaluation completion, source content exactly matched the frozen final snapshot.

The next acceptance run needs filesystem isolation that prevents installed-skill reads, complete equivalent smaller-model cohorts, a clean smaller-model confirmation, observable primary-page retrieval and the missing narrow-ADR cost/trigger behavior. Any semantic skill change requires a new frozen snapshot and new comparison; old results cannot certify it. The current version remains `1.1.0-rc.1`.

These conclusions cover only the named model IDs, reasoning setting and authored cases. Single-turn interview adaptation, explicit skill loading and proposed experiments do not validate live interview dialogue, automatic activation or actual production recovery.
